# Хронотоп вселенной Гарри Поттера

Интерактивный литературный атлас — временная карта магической Британии от основания
Хогвартса (ок. 990) до «Проклятого дитя» (2020).

**186 карточек · 16 дорожек · 70 тэгов · 227 перекрёстных связей**

Собран на том же движке, что «Общий хронотоп Бориса Акунина»: standalone `index.html`
с инлайновым `const DATA=[...]`, без сборки и без внешних зависимостей.

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | Атлас целиком: разметка, стили, движок и данные в одном файле |
| `data/potter.json` | Те же карточки отдельным файлом, для правок и переиспользования |
| `.nojekyll` | Отключает обработку Jekyll на GitHub Pages |

## Два измерения чтения

Шкала читается слева направо — это хронология. **Тэги дают поперечное чтение:** клик по
тэгу оставляет на шкале только карточки с ним, в любой дорожке и любом веке. Например,
«жертва» собирает семь точек из пяти дорожек за сто лет — Ариану 1899, Литу 1927,
Регулуса 1979, Годрикову Впадину 1981, Лесной путь 1998.

Переключатель «Совпадение» задаёт логику: *любой из выбранных* даёт объединение,
*все выбранные сразу* — пересечение. Тэги внутри открытой карточки кликабельны.

### Словарь

в 4 карточки**; всё, что реже, осталось в свободном поле `motifs`. Порог проверяется
при сборке и роняет её при нарушении.

Пять карточек имеют по одному тэгу (`ad-birth`, `ad-teacher`, `fb-escape`, `fb-book`,

пиктограммы карточки: `icon()` гоняет регулярки по склейке `motifs + location +
layer_type + title`.

## Про интерпретационный пласт

«Большая Игра профессора Дамблдора» — исследование anna_y и cathereine, публиковавшееся
в ЖЖ [big_game](https://big-game.livejournal.com/) с мая 2005 по июль 2008 года. Его
посылка: сюжетные нестыковки Роулинг — не ошибки автора, а ходы персонажа, который
«любит находиться не на шахматной доске, а за доской».

Это **не канон**. Все карточки пласта вынесены на две отдельные дорожки, помечены
штриховкой, имеют достоверность «Низкая» и предупреждение внутри карточки. Кнопка
**«Только канон»** в тулбаре убирает пласт целиком.

У 20 канонических карточек внутри есть блок «Прочтение по Большой Игре» — альтернативная
трактовка того же события.

Рамка теории принципиально нефальсифицируема: любая странность текста автоматически
становится её подтверждением. При этом тем же методом до выхода седьмой книги были
предсказаны договор Дамблдора со Снеггом, личность Р. А. Б. и то, что Гарри сам является
хоркруксом. Несбывшиеся прогнозы вынесены отдельной карточкой.

## Управление

- **Шкала** — три режима: сжатый обзор, линейная, крупный план 1991–1998
  (семь школьных лет на всю ширину, всё остальное скрыто)
- **Достоверность** — «Высокая» (дата названа в тексте), «Средняя» (выводится),
  «Низкая» (широкий диапазон, смежный канон или гипотеза)
- Клик по названию дорожки сворачивает её; полотно таскается мышью
- Печать даёт A0 landscape

## Схема карточки

```
id · author · cycle · title · parent · form
start_year · end_year · pos · pos_end · date_label · short_date
location · characters · layer_type · confidence · status
basis · source · source2 · notes · motifs · tags · scope · connections · bi
```

`pos` и `pos_end` — дробный год для позиционирования с точностью до месяца
(`1997.5` = июнь 1997). `tags` — значения из закрытого словаря. `bi` — прочтение
по «Большой Игре», пустое у большинства карточек.
